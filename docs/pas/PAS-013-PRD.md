# PAS-013 — Product Requirements Document

**中文名：** 产品需求规格文档
**产品阶段：** Alpha v0.1
**版本：** 0.1

## 产品概述

PAS 是帮助用户长期探索体验、识别心理模式并建立个人自我理解模型的平台。它不是医疗诊断、心理治疗、人格测试或重大决策代理。

## 目标用户

1. 对自己保持好奇的自我探索者；
2. 处于学业、职业、关系或身份转折期的用户；
3. 感觉卡住，希望理解反复模式的用户。

Alpha 不主动招募正在经历急性危机、期待诊断或需要专业治疗替代的人群。

## 核心用户流程

```text
了解定位与边界
→ 注册并设置记忆偏好
→ 开始一个探索主题
→ 获得镜像式回应
→ 继续澄清与现实检验
→ 确认或拒绝候选记忆
→ 查看探索历史和当前心理地图
→ 修正、删除或导出数据
```

## P0 功能

### Landing Page

展示产品定位、非诊断边界、隐私承诺和“开始探索”入口。

### Authentication

支持邮箱登录；第三方登录可后续加入。所有用户资源必须与认证用户绑定。

### Reflection Room

支持创建会话、发送消息、流式或普通响应、错误恢复、当前主题展示和安全提示。

### Conversation Engine

执行风险检测、上下文构建、相关记忆检索、PAS 回应生成、输出审核和候选记忆提取。

### Memory Confirmation

候选记忆必须展示来源和表述，由用户确认后才能进入长期模型。

### Data Controls

支持查看、修改、删除、导出、关闭长期记忆和删除账户。

## P1 功能

- 探索历史与主题整理；
- 阶段性 Reflection Summary；
- 简单心理地图；
- 用户反馈与 AI 纠错；
- Prompt 和安全规则版本记录。

## 数据模型

至少包含：

- `profiles`
- `conversations`
- `messages`
- `memories`
- `themes`
- `summaries`
- `consents`
- `audit_events`

所有公开表启用 RLS；用户只能访问自己的行。服务端特权密钥不得传递给客户端。

## AI 行为验收

- 不诊断、不贴标签；
- 不把假设表述为事实；
- 一次优先提出一个有价值问题；
- 承认感受但不强化不实判断；
- 尊重用户纠正；
- 危机时切换安全流程；
- 不使用依赖诱导语言。

## MVP 完成标准

用户能够注册、开始连续探索、获得 PAS 风格回应、保存会话、确认记忆、查看主题、控制数据；关键安全测试、RLS 测试和删除测试全部通过。
