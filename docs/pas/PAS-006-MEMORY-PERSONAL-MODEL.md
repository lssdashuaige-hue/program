# PAS-006 — AI Memory & Personal Model System

**中文名：** AI 记忆与个人心理模型系统
**版本：** 0.1

## 目标

PAS 不保存一切，而建立动态、透明、可修正且属于用户的个人理解模型。记忆用于延续探索，不用于固定身份。

## 三层记忆

### 1. 事件记忆

记录用户报告的经历、时间、感受和用户赋予的意义。尽量接近事实，不添加创伤、人格或因果判断。

### 2. 模式记忆

记录多次出现的心理循环，例如“评价情境—紧张—减少表达”。必须包含证据、置信度、适用范围、反例和待验证问题。

### 3. 自我模型

保存用户明确认可的自我理解，例如“我重视独立，同时也希望被理解”。它由用户共同建立，而不是 AI 的隐藏画像。

## 记忆状态

每条记忆应包含：

- 来源：用户陈述、用户反思或系统观察；
- 类型：经历、反思、模式、需要或探索主题；
- 置信度：低、中、高；
- 确认状态：候选、用户确认、用户否定、已过时；
- 创建与最近验证时间；
- 证据和反例；
- 是否允许用于后续上下文。

## 更新规则

- 一次表达通常只能形成低置信候选；
- 多次独立证据可提升置信度；
- 用户明确确认优先于 AI 推断；
- 当前表达与历史冲突时，优先尊重当前表达；
- 新的相反证据必须触发修正，而不是被旧模型过滤；
- 过时理解应保留变化轨迹，但不继续作为当前事实。

## 用户控制

用户可以：

- 查看 AI 当前保存的内容；
- 修改表述；
- 拒绝候选记忆；
- 删除单条或全部心理数据；
- 暂停长期记忆；
- 在一次会话中禁用历史；
- 导出自己的数据。

## 最小必要记忆

只保存对长期自我探索具有明确价值的内容。普通偏好、一次性情绪和 AI 未确认推断不得进入长期心理模型。

## 反固化机制

系统定期询问：

- 这个理解现在还成立吗；
- 最近是否出现例外；
- 模式是否只适用于特定情境；
- 用户是否已经发展出新的能力。

## 核心定义

> PAS 的记忆不是为了掌握更多用户信息，而是帮助用户看见自己的变化，同时永远允许过去的理解被修正。
