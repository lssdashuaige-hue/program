# PAS-002 — Core Psychological Model

**中文名：** 核心心理模型
**状态：** Alpha 设计基线
**版本：** 0.1

## 核心假设

1. 行为通常在特定心理和现实背景中具有功能。
2. 心理模式由个人、经历、关系、环境和当前现实共同形成。
3. 很多“问题行为”曾经是有效的适应或保护方式。
4. 人会变化，任何模型都只能代表当前理解。
5. 用户体验优先于 AI 理论。

PAS 不寻找“谁有错”，而探索一个模式如何形成、曾保护什么、付出什么代价，以及今天是否仍然适用。

## 五层心理结构

### 1. 外显行为

可观察的行动，例如拖延、回避、讨好、沉默、控制或生气。行为是入口，不是结论。

### 2. 情绪与身体体验

识别行为下的焦虑、愤怒、失望、羞耻、疲惫、孤独，以及呼吸、紧绷、心跳等身体信号。

### 3. 自动化认知

探索事件发生时快速出现的解释，例如“他不回复就是讨厌我”或“犯错就会被否定”。

### 4. 核心信念

观察用户长期如何理解自己、他人和世界，例如“必须优秀才值得认可”或“只有依靠自己才安全”。

### 5. 深层需要与冲突

识别同时存在的需要，例如既想靠近又害怕受伤、既渴望认可又抗拒被评价。PAS 不把这些体验简化为矛盾人格。

## 自我探索循环

一次完整探索优先经历：

1. **事件：** 发生了什么；
2. **体验：** 当时有哪些情绪和身体反应；
3. **解释：** 脑中出现了什么想法；
4. **模式：** 是否在其他情境反复出现；
5. **形成：** 这种方式可能如何发展出来；
6. **现实检验：** 现在的事实是否仍支持旧解释；
7. **整合：** 如何理解、接纳并尝试新的选择。

系统不要求每次对话走完全部步骤，也不以固定问卷审问用户。

## 输出边界

- 使用概率性语言，不制造确定因果。
- 同时保留多种合理假设。
- 区分用户明确表达、历史事实和 AI 推测。
- 未经用户确认的模式不得成为稳定记忆。
- 所有理解最终必须回到现实功能和行动自由。

## 目标模型

用户逐渐能够回答：

- 我的触发点是什么；
- 我的情绪和自动想法是什么；
- 我通常如何保护自己；
- 我的核心需要是什么；
- 哪些模式仍在帮助我；
- 哪些模式已经限制我；
- 我现在可以怎样更自由地选择。
