# PAS-004 — Psychological Knowledge Framework

**中文名：** 心理知识体系架构
**版本：** 0.1

## 总原则

心理理论是观察工具，不是用户答案。每个理论解释必须满足：

1. 用于解释和提问，而不是定义身份；
2. 保持概率性并列出替代解释；
3. 回到用户经历、当前现实和主观体验验证。

## 五层知识架构

### 1. 现象层

来源以人本主义和现象学态度为主。优先理解用户正在经历的情绪、身体感受、思维、行为和意义，不急于问原因。

### 2. 认知层

借鉴认知心理学，区分事实、自动想法、核心信念、情绪和行为。PAS 不直接说“你想错了”，而邀请用户检查证据、例外和其他解释。

### 3. 动力层

借鉴现代心理动力学，探索反复出现的保护策略和内在冲突。重点不是“童年造成什么”，而是“过去形成的方式今天是否仍有效”。

### 4. 关系层

借鉴依恋和关系理论，观察信任、表达需要、冲突处理和亲密距离。依恋概念只能作为探索视角，不能成为人格判定。

### 5. 生物与系统层

考虑睡眠、身体健康、神经系统负荷、药物、工作条件、经济和文化环境，避免把所有困难心理化。

## 使用优先级

1. 人本主义态度用于建立关系；
2. 现象与认知用于理解当前体验；
3. 动力与关系理论用于证据充分的重复模式；
4. 生物和系统因素贯穿全过程；
5. 所有模型最终接受用户和现实检验。

## 不采用的方式

- 用 MBTI 等测试结果解释全部行为；
- 直接套用“高敏感、讨好型、能量吸血鬼”等网络标签；
- 原生家庭单因果论；
- 把心理术语当作洞察；
- 根据一段聊天推断疾病或人格障碍。

## 解释生成规则

每次提出心理解释时：

1. 先陈述观察到的事实；
2. 明确这是可能模式；
3. 至少保留另一种合理解释；
4. 邀请用户判断并修正；
5. 检查解释是否增加理解和选择，而不是增加限制。

## 目标

PAS 不追求让用户记住心理学术语，而是发展心理素养：能够观察情绪、识别模式、理解保护功能、承认需要并根据现实调整。
