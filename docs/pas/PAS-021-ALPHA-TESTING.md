# PAS-021 — Alpha Testing & User Feedback System

**中文名：** Alpha 测试与用户反馈系统
**版本：** 0.1

## 测试目标

Alpha 不用于证明 PAS 已经优秀，而用于发现它在哪里仍然不理解人。核心假设：

1. 用户愿意表达真实而复杂的体验；
2. PAS 能促进新的自我理解；
3. 连续探索比一次问答更有价值；
4. 记忆和心理地图准确、可修正且不造成固化；
5. 安全边界在真实语言中仍然有效。

## 测试用户

优先招募 20～50 名：

- 有写日记或自我反思习惯的人；
- 处在人生变化期的人；
- 感觉卡住但当前没有急性危机的人。

清楚告知这是 Alpha 自我探索工具，不是专业治疗或诊断服务。

## 七日探索建议

- Day 1：最近反复思考的事情；
- Day 2～3：深入一个具体情境；
- Day 4～5：整理重复主题和例外；
- Day 6：用户修正系统理解；
- Day 7：阶段总结、现实影响和安全反馈。

测试安排不是强制治疗流程，用户可随时跳过和退出。

## 反馈维度

- 理解感；
- 新发现程度；
- 镜像准确性；
- 是否被判断或误解；
- 现实行为影响；
- 记忆准确性；
- 数据控制清晰度；
- 是否感到依赖诱导。

## Failure Library

失败案例分类：

- 过早解释；
- 过度安慰；
- 连续审问；
- 术语过多；
- 错误或越界记忆；
- 忽略现实因素；
- 强化绝对叙事；
- 危机识别失败；
- 依赖语言；
- 数据与 UI 误导。

案例库必须去标识化，并受测试同意范围约束。

## Alpha 结束标准

- 用户理解 PAS 的类别和边界；
- 关键安全案例稳定通过；
- 用户可以纠正和删除模型；
- 出现可重复的 Insight 信号；
- 未发现严重跨用户数据泄漏；
- 已知失败模式有明确缓解计划。
