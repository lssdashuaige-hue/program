# PAS-005 — User Experience Architecture

**中文名：** 用户体验架构
**版本：** 0.1

## 核心体验

PAS 的入口不是“解决心理问题”，而是激发用户对自己的好奇：

```text
好奇 → 观察 → 理解模式 → 接纳 → 现实调整 → 自主反思
```

用户应感觉自己正在理解自己，而不是正在被系统分析。

## 入口体验

首页核心信息：

- 认识自己是每个人都可以进行的探索；
- PAS 不做心理诊断或人格定型；
- 用户可以从最近困惑、人生选择、关系事件或当天体验开始；
- 主行动使用“开始探索”，避免“开始治疗”或“解决问题”。

## 探索空间

核心界面称为 Reflection Room，而不是普通聊天室。它包含：

- 当前探索主题；
- 对话与反思区域；
- 用户可选的探索提示；
- 当前理解和待确认内容；
- 通往探索历史与心理地图的入口。

界面不展示虚假的心理进度、诊断分数或确定性结论。

## 心理地图

地图使用“当前探索”语气，主要包含：

- 容易触发我的情境；
- 我常见的情绪和反应；
- 可能的保护方式；
- 我重视或需要什么；
- 我正在尝试的新方向；
- 用户确认状态和可修正入口。

## 长期旅程

1. **Self Discovery：** 发现自己的体验；
2. **Pattern Recognition：** 看见重复循环；
3. **Self Acceptance：** 理解模式曾经的功能；
4. **Reality Adjustment：** 在现实中尝试不同选择；
5. **Self-guided Reflection：** 用户可以独立完成更多观察。

这不是等级系统，不以连续打卡或使用天数衡量成长。

## 反依赖设计

- 初期由 AI 提供更多结构；
- 中期让用户先提出可能解释；
- 后期让用户回顾自己会如何观察；
- 提醒现实支持和现实行动；
- 不通过孤独感、焦虑或未完成感召回用户。

## 页面范围

MVP 优先：

1. 首页；
2. 登录与隐私说明；
3. Reflection Room；
4. 探索历史；
5. 简单心理地图；
6. 数据与记忆设置。

## 成功标准

不以最大停留时间为目标。成功体验是用户能说：

> 这像是我自己逐渐形成的理解，而不是 AI 给我的标签。
