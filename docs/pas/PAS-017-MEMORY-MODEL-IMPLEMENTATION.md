# PAS-017 — Memory & Personal Psychological Model Implementation

**中文名：** 长期记忆与个人心理模型实现
**版本：** 0.1

## 实现目标

构建“越来越了解用户，但不把用户固定下来”的动态模型。记忆系统优化相关性、透明度和可修正性，而不是记忆数量。

## 四类可持久数据

1. **Experience：** 用户报告的具体经历；
2. **Reflection：** 用户自己的理解；
3. **Pattern：** 多次证据支持的重复循环；
4. **Personal model statement：** 用户明确认可的当前自我表述。

一次性情绪、普通偏好、模型内部推理和未经确认的标签不可持久化为心理模型。

## 数据字段

建议包含：

- `id`, `user_id`, `type`, `content`；
- `status`, `confidence`, `user_confirmed`；
- `source_message_id`；
- `evidence_count`, `counter_evidence`；
- `valid_from`, `last_reviewed_at`, `superseded_by`；
- `memory_enabled_at_capture`；
- embedding 字段仅在后续启用。

## 候选到确认

```text
模型发现候选
→ 后端检查是否允许保存
→ 向用户展示准确表述
→ 用户确认、修改或拒绝
→ 保存最终版本
```

拒绝本身可以用于避免重复误解，但不得被保存为新的心理标签。

## 检索

MVP 优先使用：

- 当前主题；
- 结构化类型；
- 最近验证时间；
- 文本搜索；
- 少量候选排序。

后续再加入 pgvector。检索结果必须限制数量，并清楚标注来源与置信度。

## 模型修正

出现相反证据时：

- 不删除对用户成长有意义的历史；
- 将旧条目标记为已过时或被新条目替代；
- 心理地图默认展示当前版本；
- 允许用户查看变化轨迹；
- 后续回应不得继续把旧条目当事实。

## 安全与隐私

- RLS 按用户所有权隔离；
- 后端只使用最小权限；
- 删除请求覆盖证据、embedding 和模型快照；
- 导出中标明数据来源和确认状态；
- 禁止在日志中复制心理正文。

## 验收

- 未确认内容不会出现在持久心理地图；
- 用户修改后检索使用新版本；
- 关闭记忆后不产生新候选；
- 用户 A 无法读取用户 B 数据；
- 删除后 API 和检索均不可访问。
