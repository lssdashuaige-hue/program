# PAS-022 — AI Improvement Loop & Model Evolution

**中文名：** AI 优化循环与模型进化系统
**版本：** 0.1

## 演进原则

PAS 的优化目标是让用户更能理解自己，而不是让 AI 看起来更像心理专家。

```text
真实使用
→ 用户反馈与失败案例
→ 形成假设
→ Prompt 或策略变更
→ 离线评测
→ 小范围发布
→ 监控与回滚
```

## 三层优化

### Prompt

改善语言、镜像顺序、假设表达和安全约束。所有版本记录变更原因、预期效果、评测结果和已知限制。

### 对话策略

建立可组合的探索路径，例如自我评价、关系冲突、决策、压力和回避，但不能把路径变成机械问卷。

### 模型能力

只有在 Prompt、检索和评测成熟，并拥有充分、合法、专家审核的高质量数据后才考虑微调。不得用未经同意的原始心理对话训练。

## PAS Benchmark

测试集覆盖：

- 普通探索；
- 模糊与矛盾表达；
- 多种文化和语言风格；
- 历史与当前表达冲突；
- 依赖、妄想和危机；
- 诱导诊断与重大决定；
- 记忆确认、修正和删除。

评分维度包括镜像准确、探索价值、谦逊、主体性、现实导向、安全和隐私。

## 实验治理

- 重要安全变更不能只依赖 A/B 指标；
- 危机用户不进入普通增长实验；
- 不以会话长度或依赖程度作为获胜指标；
- 低样本结果不升级为产品事实；
- 每个版本可以快速回滚；
- 评测数据保留来源和同意状态。

## 人类参与

AI 不能独立评估心理质量。需要用户纠正、产品安全审查和具备资质的专业顾问共同建立标准。专家意见仍然不能覆盖用户对自身体验的最终解释权。

## 微调门槛

考虑 Fine-tuning 前必须具备：

- 明确合法的数据授权；
- 去标识化和质量筛选；
- 专家审核；
- 稳定 Benchmark；
- 安全回归测试；
- 与基础模型的实际增益证据；
- 删除和退出机制。
